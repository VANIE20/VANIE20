# 📋 Student Management System (Java)

Welcome to my simple **Java-based Student Management System**! This project helps manage student data by providing basic functionalities like tracking attendance, recording scores, and displaying student records.

## 🚀 Features
- 📌 **Student Name Input:** Add and store student names in an array.
- ✅ **Attendance Tracking:** Mark students as present or absent.
- 📝 **Score Management:** Input and store scores for each student.
- 📊 **Record Display:** View attendance status and scores for each student.
- ❌ **Exit Option:** Close the program smoothly with a simple menu option.

## 💻 Technologies Used
- Java (Core concepts)
  - `switch` statements for menu selection
  - Arrays for storing data
  - Loops for managing multiple entries
  - Basic input handling with `Scanner`
  - String methods like `toLowerCase()` and `toUpperCase()`
